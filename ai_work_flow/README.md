# ai_work_flow

Documentación metodológica del proyecto Omega Gym.

## Estructura

- `docs/specs/` — Especificaciones del proyecto
  - `SPECIFICATION.md` — Especificación principal
  - `incremental/` — Specs para cambios grandes posteriores
- `knowledge/` — Base de conocimiento
  - `local/` — Decisiones técnicas internas y lecciones aprendidas
  - `remote/` — Referencias a documentación oficial
- `tickets/` — Tickets internos de desarrollo (TKT-OMEGYM-###)
